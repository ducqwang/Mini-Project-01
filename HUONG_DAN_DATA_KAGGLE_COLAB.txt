--------------------------------------------------------------------------------
KHÔNG cần tự đi kiếm ảnh. Dùng bộ công khai sẵn có trên Kaggle:
    Tên : "Animal Image Dataset: DOG, CAT and PANDA"
    Slug: ashishsaxena2209/animal-image-datasetdog-cat-and-panda
    (gồm 3 thư mục lớp: cats / dogs / panda, mỗi lớp ~1000 ảnh; chưa chia val

 CÁCH 1 — Chạy trên KAGGLE (khuyến nghị cho bạn cùng nhóm):

   2) Panel bên phải -> "Add Input" -> gõ "Animal Image Dataset DOG CAT PANDA"

   3) Settings -> Accelerator: GPU T4  (và Internet: On nếu muốn auto-tải VOC ở NB02).
   4) Run All. Notebook tự dò thư mục lớp trong /kaggle/input và chạy.
   -> Nếu không add dataset mà bật Internet, cell môi trường sẽ tự tải bằng kagglehub.

 CÁCH 2 — Chạy trên COLAB:
   1) Upload cả thư mục project lên Drive thành  MyDrive/MiniProject01  (tùy chọn).
   2) Mở notebook 01 trên Colab -> Runtime -> GPU.
   3) Run All. Nếu Drive chưa có ảnh, cell môi trường sẽ tự tải bằng kagglehub
      (cần đăng nhập Kaggle nếu bị hỏi token — xem mục 4).

 Muốn DÙNG CHUNG đúng 1 bản train/val cho cả nhóm? Xem mục 5 (đóng gói & upload).

2. DỮ LIỆU PHÁT HIỆN ĐỐI TƯỢNG (Notebook 02) — cat / dog / panda (chuẩn YOLO)
--------------------------------------------------------------------------------
 - cat & dog: TỰ ĐỘNG tải từ Pascal VOC 2007 (torchvision, cần Internet: On).
              Không cần làm gì, chỉ cần bật Internet trên Kaggle.
 - panda    : cần 1 dataset panda có bounding box (định dạng YOLO: images/ + labels/*.txt).
              Notebook sẽ TỰ DÒ thư mục có chữ "panda" + có nhãn .txt rồi nạp.

   Lấy panda ở đâu (chọn 1):
     a) Roboflow Universe (export YOLOv8). Vài project có sẵn:
          - https://universe.roboflow.com/program1/panda_detection        (~288 ảnh)
          - https://universe.roboflow.com/xdgyifeng/panda-detection-yoo4d
          - https://universe.roboflow.com/attha/panda-skne0               (~40 ảnh)
        Mở project -> Download Dataset -> Format: YOLOv8 -> tải zip về.
     b) Trên Kaggle: giải nén zip panda, tạo một Kaggle Dataset từ nó (hoặc tìm
        dataset panda-bbox có sẵn), rồi "Add Input" vào notebook 02.
        -> Đặt tên thư mục/dataset có chữ "panda" để cell tự dò, HOẶC mở cell "2b"
           và set thủ công:  PANDA_SRC = "/kaggle/input/<ten-dataset-panda>"
     c) Colab/Local: giải nén panda vào 1 thư mục có images/ + labels/, rồi set
           PANDA_SRC = r"đường/dẫn/panda_yolo"

   (Nếu tạm thời chưa có panda: NB02 vẫn chạy với cat/dog, nhưng để ĐỦ 3 lớp
    theo yêu cầu đề thì nên bổ sung panda.)
